## Выбранный объём и реализация

Клиентское приложение помогает подобрать регулярные занятия в Екатеринбурге
для себя или близкого человека и составить недельный план с ориентировочной
месячной стоимостью. Стек: React, strict TypeScript, Vite, React Router,
локальные JSON, localStorage, ESLint, Vitest.

| Требования | Найденная реализация |
| --- | --- |
| FE-001–005 | TS/TSX, конфигурации, шесть маршрутов, структура `app/src`, доменные типы `types/domain.ts` |
| FE-006–007 | `data/catalog`: 13 групп, 15 сессий, 4 направления, 3 площадки, 2 организатора и 2 преподавателя; нормализация и диагностика |
| FE-008–013 | `utils/business`: расчёт стоимости, фильтры AND/OR, стабильный порядок, пересечения, дорожный порог 29/30 минут, агрегат плана |
| FE-014–022 | Home, Help Select из пяти параметров, Catalog; normalize → filter → order → render, пустая выдача и маркировка учебных данных |
| FE-023–024 | Локальный поиск, дополнительные фильтры уровня, нагрузки и доступности, очистка условий без изменения плана |
| FE-025–027 | Detail со связанными данными; уникальное добавление только из Detail; успешное и нейтральное состояния Added |
| FE-028–032 | My Plan 0..N, все недельные сессии, предупреждения, удаление/Undo, безопасное сохранение и восстановление |
| FE-033–037 | Адаптивность, клавиатура, focus, семантика и контраст; подробная матрица в `app/UI_REVIEW_FE033_037.md` |

Активное приложение не зависит от JSX-модулей. Legacy-код сохранён отдельно,
старые разовые события не подмешиваются в новый каталог и план.
Матрица подтверждает наличие реализации; ограничения проверки приведены ниже.

## Основной пользовательский сценарий

Home → Catalog → Activity Detail → Activity Added → My Plan.
Необязательная ветка: Home → Help Select → Catalog. Пользователь редактирует
фильтры и поиск, читает условия, добавляет уникальные группы без лимита четыре,
видит недельное расписание, сумму и информационные предупреждения. План
восстанавливается после перезагрузки; последнее удаление можно отменить до reload.

Хранится только ActivityPlan: `activityIds`, `monthlyBudget`,
`estimatedMonthlyTotal`, `createdAt`, `updatedAt`. Поиск, анкета, временные фильтры,
Undo и контекст Added не записываются в localStorage.

  Оба заменены инструкциями запуска, описанием сценария, ограничений и роли ИИ.
- Локальные `mobile-check.png`, `route-check.pdf`, устаревший
  `verify-scenario.mjs` и `.stage-*` исключены точными правилами `.gitignore`.
  Файлы не удалялись. Устаревший скрипт не использовался для проверки нового MVP.
- Ранее при FE-033–037 исправлены потеря focus, маленькие области нажатия,
  контраст границ, клавиатурная навигация и локализация; подробности в UI-отчёте.
