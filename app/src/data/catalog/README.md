# Локальный источник регулярных групп — FE-006 / FE-007

Это **учебные вымышленные данные**, не афиша и не подтверждённые предложения.
Названия организаторов, преподавателей и площадок явно демонстрационные.
Адреса не предназначены для посещения. Реальная запись и подключение не
осуществляются. Контакт учебного проекта `ekanitki@gmail.com` предоставлен
владельцем и указан у демонстрационных организаторов через mailto, а также
в supportContact online/hybrid-групп. Это контакт проекта, не реальных площадок.
Неизвестные телефоны и сайты по-прежнему пропущены или равны null.

## Вход и использование

`demo/` содержит шесть JSON-массивов: `directions`, `organizers`, `venues`,
`instructors`, `groups`, `schedules`. Старый `../activities.json` не изменён.

Будущие потребители получают новый набор через:

```ts
import { getCatalogData } from './data/catalog'
const { data, diagnostics, stats } = getCatalogData()
```

API не делает сетевых запросов и не пишет в localStorage. Каждый вызов
возвращает отдельный нормализованный снимок. Новый Catalog использует этот слой.
`normalizeCatalog(unknown)` также доступен для проверки произвольного входа.
В dev-режиме loader выводит диагностические сообщения с коллекцией, индексом,
ID, полем, кодом и причиной. Во всех режимах диагностика доступна в результате.

## Нормализация

- У каждой коллекции собственное пространство ID. Все записи с повторённым ID
  исключаются, чтобы не выбирать произвольную версию; зависимые ссылки тоже
  исключаются. Исходный порядок оставшихся записей сохраняется.
- Обязательные поля, enum из `types/domain.ts`, числа, строковые массивы,
  даты, ссылки и nullable-поля проверяются до использования.
- Невалидная коллекция даёт пустую коллекцию и диагностику; невалидная запись
  не обрушает остальные данные. Циклы и отсутствующие родители Direction
  исключаются вместе с зависимыми направлениями.
- Schedule использует ISO weekday 1–7, строгое HH:mm и startTime < endTime.
  Только валидные сессии считаются в lessonsPerWeek. При расхождении группа
  исключается, затем удаляются её оставшиеся сессии. Значения не подделываются
  и lessonsPerWeek не исправляется молча.
- Для offline/hybrid нужна существующая площадка. Для online допустимы
  отсутствующий/null venueId; любой переданный ID должен существовать.
- onlineDetails необязателен согласно доменной модели. Для online/hybrid
  проверяются переданные поля, неизвестные поля не копируются. Отсутствующие
  применимые значения остаются неизвестными. Для offline валидный, но
  неприменимый блок удаляется с предупреждением.
- availablePlaces не превышает известную capacity; отрицательные/нечисловые
  цены и количества исключаются. У free цена должна быть 0. У неизвестной
  доступности сохраняется null/отсутствие, без преобразования в false.
- Веб-ссылки проверяются структурно, contactLink также допускает mailto.
  Это не подтверждение достоверности контакта; данные не дополняются из сети.

## Граница FE-008

`estimatedMonthlyCost` из JSON всегда игнорируется с диагностикой. Поле
не заменяется нулём. `ValidatedActivityGroup` —
распределённый Omit от существующего ActivityGroup только без производного
поля; все остальные поля и дискриминатор площадки сохранены. Это вход для
расчёта FE-008, а не новая конкурирующая модель. Реализованная чистая функция
`calculateCatalogCosts(data)` из `utils/business` дополняет нормализованные
группы пересчитанной стоимостью и возвращает полноценные ActivityGroup.

Фильтрация, упорядочивание, стоимость, конфликты, дорожные предупреждения
и агрегирование плана реализованы отдельно в `utils/business` (FE-008–013).
Catalog подключён к функциям фильтрации и упорядочивания. Сам нормализатор не сортирует выдачу
и не выполняет бизнес-расчёты.

## Покрытие демонстрационных сценариев

В наборе 13 групп, 15 Schedule-сессий, 4 направления, 3 площадки в разных
районах Екатеринбурга, 2 организатора и 2 преподавателя.

| Сценарий | Записи |
| --- | --- |
| Две сессии в неделю, perLesson 500 | group-walk, понедельник и четверг |
| Пересечение в понедельник | group-walk 10:00–11:00 и group-art 10:30–12:00 |
| 29 минут между разными очными площадками | group-walk → group-gap29, 11:00 → 11:29 |
| Ровно 30 минут | group-walk → group-gap30, 11:00 → 11:30 |
| Пересечение границы утро/день | group-walk в четверг 11:30–12:30 |
| Онлайн без venueId и с venueId=null | group-online, group-budget |
| Гибридный формат, rollingModules/nextModule | group-hybrid |
| Бесплатно / помесячно / за занятие | group-art / group-gap29 / group-walk |
| Будущее превышение бюджета 2000 | group-gap29 с месячной ценой 2500 |
| Две сессии perLesson 1500 | group-budget |
| Неактивные и закрытые варианты | group-paused, group-completed, group-planned, group-closed |
| Лист ожидания и будущий набор | group-waitlist, group-future |
| Условия участия | group-walk, group-art |
| Неизвестная/да/нет доступность | venue-a, venue-b, venue-c |

Представлены все дни недели и утренние, дневные, вечерние начала занятий.
Неактивные и закрытые группы остаются в нормализованном наборе: фильтр
основной выдачи active + openNow относится к FE-009/016.

У каждого демонстрационного организатора есть contactLink учебного проекта,
предоставленный владельцем: `mailto:ekanitki@gmail.com`. У group-online и
group-hybrid заполнены все четыре поля onlineDetails, включая supportContact.
Контактное покрытие FE-007 проверяется скриптом; работоспособность почтового
ящика и доставка писем автоматически не проверяются.

## Проверка

`npm.cmd run check:catalog` проверяет корректный набор и повреждённые копии
в памяти: поля, enum, duplicate ID, ссылки, время, числовые границы, каскадное
исключение, неизвестные optional-поля, недоверие monthly cost и независимость
снимков. Проверка не меняет JSON. Это проверка FE-006/007.
`npm.cmd test` запускает Vitest для реализованных правил FE-008–013.
`npm.cmd run check` выполняет обе проверки последовательно.
