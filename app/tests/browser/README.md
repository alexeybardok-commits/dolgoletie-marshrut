# Браузерная инфраструктура ЛР7

Установите зависимости приложения через `npm.cmd ci`. Нужен установленный
Microsoft Edge: конфигурация использует `channel: 'msedge'` без скачивания Chromium.

Команда `npm.cmd run test:e2e` запускает Playwright из зависимостей проекта.
Playwright сам запускает Vite на `http://127.0.0.1:4173` и останавливает его
после проверки. Порт должен быть свободен; чужой сервер не переиспользуется.
Проекты: Edge с viewport 1440×900 и 390×900. Второй проверяет узкую ширину,
но не эмулирует реальное сенсорное устройство. Повторные попытки отключены.

Интеграционный L7-01 выполняется через Vitest. Браузерный набор в `lab7/`
содержит восемь сценариев для трёх требований:

| Требование | Тесты | Ожидаемый результат |
| --- | --- | --- |
| R1 — поиск и фильтры | R1-01 | Поиск «акварель» даёт одну группу; совместимые условия дают акварель и рисунок; бюджет 0 оставляет акварель; неизвестный запрос даёт Empty; отдельное удаление сохраняет другие условия; сброс возвращает семь групп |
| R1 — online и порядок | R1-02 | Район + бюджет сохраняют подходящую online-группу; hybrid идёт перед online; запрос «цифровые» оставляет цифровые навыки |
| R2 — уникальность | R2-01 | Detail → Added → My Plan; одна ходьба за 4000 ₽; повторное открытие Detail показывает disabled «Уже в плане», storage не меняется |
| R2 — отсутствие лимита | R2-02 | Пять групп, сумма 9500 ₽; временные и дорожные предупреждения не блокируют добавление |
| R3 — reload | R3-01 | Три группы, четыре сессии, сумма 4000 ₽ и бюджет 5000 восстанавливаются; поиск и направление сбрасываются; общий сброс сохраняет выбранные ID |
| R3 — повреждение | R3-02, два варианта | Неразбираемый JSON и объект неверной структуры дают пустой план; последующее добавление и reload работают |
| R3 — частичное восстановление | R3-03 | Дубликаты и неизвестные ID исключаются, бюджет-строка становится null, устаревшая сумма пересчитывается до 4000 ₽; legacy-ключ не меняется |

Каждый тест получает новый браузерный контекст с пустым `storageState`.
Повреждённые данные записываются однократно перед полной загрузкой приложения,
после завершения его первоначальной записи. Перезагрузки не подменяются
повторным заполнением storage. Пользовательские действия выполняются через
доступные имена элементов; чтение storage служит дополнительной проверкой.
Моков бизнес-функций, фиксированных задержек и повторных попыток нет.

Запуск всего набора и просмотр HTML-отчёта (из `app/`):

```powershell
npm.cmd run test:e2e
npm.cmd exec -- playwright show-report
```

HTML-отчёты, результаты, traces и снимки внутри каталогов результатов
исключены из Git и ESLint. В ограниченной среде запуск webServer/Edge и
остановка дерева Vite могут требовать разрешения на выполнение вне sandbox.

При первом прогоне новых тестов прошли 4/16 проверок: десять падений были
вызваны неоднозначным локатором одинаковой суммы в сводке/карточке, ещё два —
неверной пунктуацией в ожидаемом предупреждении. Исправлены локаторы тестов,
проверки не отключались. ESLint сначала включал JS из сгенерированного
trace-viewer; каталоги артефактов исключены, исходники и тесты проверяются.
Бизнес-логика приложения и прежние тесты не изменялись.
