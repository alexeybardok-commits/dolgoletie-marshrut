# Долголетие Маршрут

Учебное клиентское приложение для поиска регулярных занятий в Екатеринбурге
и составления совместимого недельного плана для себя или близкого человека.
Основной сценарий рассчитан на взрослого ребёнка, помогающего родителю.

Приложение находится в **`app/`**. Требования — ТЗ v1.15 FINAL Development
Baseline и Frontend Backlog FINAL в [docs](docs/). Материалы предыдущих
лабораторных в [tempPage](tempPage/) сохранены отдельно.

## Технологии

React, TypeScript (strict), Vite, React Router, локальные JSON-данные,
localStorage, ESLint и Vitest. Backend и внешние API не требуются.

## Локальный запуск

Проверяемая среда: Node.js 24.22.1, npm 11.19.1, Windows.

```powershell
cd app
npm.cmd ci
npm.cmd run dev
```

Откройте URL, напечатанный Vite (обычно `http://localhost:5173`). Перед
повторным `npm.cmd ci` остановите dev/preview-серверы этого проекта:
в Windows работающий Rolldown может блокировать замену нативного модуля.
На macOS/Linux используйте `npm` вместо `npm.cmd`.
Переменные окружения, ключи API и отдельная настройка сервера не нужны.

## Пользовательский сценарий и функции

Home → Catalog → Activity Detail → Activity Added → My Plan.
Необязательная ветка: Home → Help Select → Catalog.

- Анкета из пяти параметров настраивает обычные редактируемые фильтры.
- Каталог регулярных групп поддерживает локальный текстовый поиск,
  направление, район, дни/время, формат и месячный бюджет; дополнительно —
  уровень, нагрузку и известную/неизвестную доступность площадки.
- Подробная страница показывает расписание, стоимость, условия участия,
  преподавателя, организатора, площадку или online-реквизиты и источник.
- Группы добавляются только с Detail, уникально и без лимита количества.
- My Plan показывает все недельные сессии и ориентировочную месячную сумму,
  предупреждает о пересечении, коротком промежутке между очными площадками
  и превышении бюджета. Предупреждения не блокируют выбор.
- Удаление пересчитывает план; Undo отменяет последнее удаление до reload.
- План сохраняется в этом браузере и устойчиво восстанавливается после reload.
  Анкета, временные фильтры, Undo и подтверждение Added не сохраняются.
- Реализованы адаптивность на 390/768/1024/1440 px, клавиатурная навигация,
  видимый focus, нативные подписи полей и русский язык документа.

## Проверки

Все команды выполняются в `app/`:

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run test
npm.cmd run check
npm.cmd run build
```

`check` запускает 41 проверку нормализатора и затем Vitest; `build` сначала
проверяет TypeScript. Последний зафиксированный UI-прогон FE-033–037:
241 тест Vitest, 41 проверка нормализатора, typecheck/lint/build — PASS;
в Edge проверены шесть маршрутов на четырёх ширинах с клавиатурой.
Результаты повторной проверки перед сдачей фиксируются отдельно в
[отчёте ЛР №6](docs/LAB6_REPORT.md), без подмены предыдущими результатами.

## Границы MVP

Все занятия, организаторы и площадки — **учебные демонстрационные данные**,
не подтверждённая афиша. Контакт `ekanitki@gmail.com` предоставлен владельцем
для учебного проекта и не выдаётся за контакт реальных площадок.
В наборе 13 регулярных групп и 15 недельных сессий.

Нет регистрации, оплаты, реальной записи, backend, карт и расчёта маршрутов,
экспорта, печати, гарантированного offline/PWA и синхронизации устройств.
Дорожное предупреждение использует фиксированный порог 30 минут.
Оценка цены за занятие использует четыре обычные недели, а не календарный месяц.
Сохранение зависит от доступности localStorage; при отказе показывается ошибка.
Screen reader и реальные сенсорные устройства отдельно не проверялись;
формальное WCAG-соответствие не заявляется. Проверка остальных браузеров
и публичного deployment пока не подтверждена.

## Роль ИИ и лабораторные работы

Codex использовался для анализа требований, поэтапной реализации, подготовки
и запуска тестов, браузерных проверок Edge, исправления ошибок и документации.
Решения и результаты проверяются по коду, командам и отчётам; участие ИИ
не заменяет самостоятельное объяснение проекта и проверку студентом.

Существующие автоматические тесты входят в рабочий MVP ЛР №6. Они **не
означают завершение ЛР №7**: для неё нужен отдельный проверяемый коммит
с дополнительными тестами и самостоятельным отчётом об изменениях.
