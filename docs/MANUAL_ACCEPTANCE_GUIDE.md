2. Для первого прохода откройте новое окно InPrivate: Ctrl+Shift+N. Так мы

3. Масштаб страницы — 100%. Сначала обычное широкое окно; узкий режим проверим
   отдельно. Версию браузера можно посмотреть через его меню «Справка / О браузере».
4. После каждого сценария напишите в чате: номер, браузер, PASS или FAIL,
   что фактически увидели. Если браузер/версия/размер неизвестны, так и запишем;
   агент не будет придумывать их по автоматическому прогону.
5. Агент заносит ваше подтверждение в журнал и только затем даёт следующий шаг.
   Если результат неясен, статус остаётся NOT VERIFIED. При FAIL фиксируем
   точное действие, адрес, ожидаемое и фактическое поведение; код сам не меняем.

PASS ставится только при выполнении всех ожиданий конкретного шага. Домашняя
страница сама по себе не закрывает весь M01 или весь браузерный FE-041.
Закрытие всех окон InPrivate очищает их storage: это не дефект приложения.
Reload проверяем в том же окне. Проверку сохранения после полного закрытия
браузера при необходимости проводим в отдельном обычном тестовом профиле.

`127.0.0.1` означает текущий компьютер. На другом ПК/Mac этот адрес не ведёт
к Windows-серверу. Для Safari нужен настоящий Safari на поддерживаемом устройстве:
либо локально собранная эта же версия на Mac, либо будущий публичный URL.
Edge не засчитывается за Chrome, а WebKit не выдаётся за реальный Safari.
Установка браузеров или публикация сейчас не выполняются.
