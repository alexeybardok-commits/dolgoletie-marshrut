## Что найдено и исправлено

- SPA-переход оставлял focus на BODY. RouteFocus переводит его на H1 новой
  страницы и возвращает начало страницы. При первоначальной загрузке обычный
  Tab-порядок сохранён. Hash-переходы внутри страницы остаются нативными.
- Нет быстрого перехода мимо повторяющейся навигации. Добавлена первая
  клавиатурная ссылка «Перейти к содержимому» с доступной целью main.
- Удаление chip, очистка поиска, сброс Empty и удаление группы теряли focus.
  Теперь это соседний chip/поиск, кнопка Undo или ссылка восстановленной группы.
- В Edge сегменты input[type=time] не активируют :focus-visible на host input.
  Для них используется видимая рамка :focus-within.
- Часть ссылок и checkbox-подписей имела высоту меньше 44 px. Увеличены
  области нажатия; для checkbox область включает связанную подпись.
- Границы inputs/selects/chips имели контраст около 2,14:1 с белым фоном.
  Новый цвет #627d72 даёт около 4,47:1. Placeholder — около 4,61:1;
  минимальное проверенное текстовое сочетание в Catalog — около 7,86:1.
  Focus #175cd3 на #f1f6f3 — около 5,48:1.
- Нативные label/for/id заменяют избыточные aria-label у select. ARIA оставлена
  для live-status, ошибок и имён повторяющихся действий, где она нужна.
- Интерактивный Undo вынесен из live-region: объявляется текст удаления,
  кнопка остаётся самостоятельным нативным действием.
- Текстовые ссылки подчёркнуты; disabled «Уже в плане» сохраняет читаемый цвет
  без opacity. Знак валюты не отделяется от суммы в карточках.
- Layout использует 1 колонку на mobile, 2 на tablet, 3 на desktop для
  каталога. Detail, недельные сессии и предупреждения переносят длинный текст.
- HTML language установлен в ru; title — «Долголетие Маршрут».

## Методика и автоматизация

- Браузерный обход всех 24 сочетаний маршрута/ширины: отсутствие overflow,
  цели не меньше 44 px, имена controls, уникальные ID, один H1, без пропуска
  уровней heading. В каждой матричной странице Tab прошёл все активные controls;
  native disabled исключён из последовательности. Native time сегменты
  проверялись по фактической рамке на host.
- Клавиши Tab, Enter, Space, ArrowDown: Home → Help Select → Catalog → Detail
  → Added → My Plan; отдельный обход main CTA и skip link; удаления и Undo.
- Визуально просмотрены viewport-снимки каждого маршрута на всех четырёх
  ширинах; дополнительно карточки и недельное расписание ниже первого экрана.
- Цветовые сочетания рассчитаны по sRGB, а не оценены только на глаз.
- Новые Vitest-проверки закрепляют русскую локализацию, landmarks, headings,
  нативные labels, live-текст, success/neutral states и семантику Undo.

## Ограничения

Это проверка доступности в объёме FE-033–037, не формальный профессиональный
WCAG-аудит и не сертификация соответствия. Screen reader и реальные
сенсорные устройства не использовались. Отдельная cross-browser-проверка
Chrome/Firefox/Safari относится к FE-041 и здесь не выполнялась.
Порядок и тексты Home сверены с ТЗ; отдельное пиксельное сравнение с Figma
не проводилось. Legacy-модули сохранены и не входят в активные маршруты.
FE-038–FE-046, deployment, commit и push не выполнялись.
